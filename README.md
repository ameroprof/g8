# جزيرة الصيانة · G8

مغامرة تعليمية ثلاثية الأبعاد باللغة العربية لطلاب الصف الثامن، لتعلّم أساسيات صيانة الحاسوب واستكشاف العتاد وأنظمة التشغيل.

## تشغيل اللعبة

افتح `index.html` في متصفح حديث مع اتصال بالإنترنت. تستخدم اللعبة مكتبة Three.js من jsDelivr لعرض الجزيرة ثلاثية الأبعاد.

- اكتب اسم الطالب والشعبة، ثم ابدأ المغامرة.
- تحرّك باستخدام `W A S D` أو أزرار الحركة على الشاشة، أو اختر محطة من قائمة الجزيرة للانتقال إليها.
- أكمل محطات الصيانة والعتاد والنظام لفتح التحدي الختامي.
- تتطلب شهادة الإنجاز نتيجة **أكثر من 70٪**. يمكن طباعتها أو حفظها بصيغة PDF.
- يستخدم زر سجل المعلم لعرض النتائج وتنزيل تقرير CSV أو طباعته.

## الخصوصية والنشر

تُحفظ النتائج في `localStorage` على الجهاز والمتصفح الحاليين فقط؛ لا تُرسل إلى خادم ولا تتزامن بين الأجهزة. لا تُدخل بيانات حساسة للطلاب.

لنشر اللعبة باستخدام GitHub Pages، ارفع `index.html` إلى جذر الفرع `main`، ثم فعّل Pages من إعدادات المستودع باختيار النشر من الفرع `main` والمجلد `/(root)`.
